​Category: Cryptography  
​DifficuLty: Easy  
​Technique: ROT13 substitution cipher decoding  
​What you learned: How symmetric substitution ciphers work by shifting alphabetic characters by 13 positions, how to use online decoding tools like CyberChef, and how platform-specific flag wrappers function.
Lab Title: Mod 26 Cryptography Challenge
​In this lab, I learned how basic substitution ciphers work by solving the Mod 26 challenge on the CyLab Security Academy platform.
​The challenge provided a text file called values.txt containing a string of jumbled letters. Since the challenge name mentioned Mod 26 and ROT13 was listed in the hints, I knew I needed to apply a 13-character letter shift to reveal the hidden text.
​I copied the encrypted string from values.txt into an online tool called CyberChef and selected the ROT13 module. The tool automatically shifted all lowercase and uppercase letters while leaving numbers, underscores, and special characters like apostrophes unchanged.
​Through this process, I learned how ROT13 works as a symmetric cipher, meaning applyng ROT13 a second time returns the text back to its original encrypted form. Replacing the standard picoCTF prefix with the platform's required academy prefix gave me the correct final answer to finish the task.

challenge 3:warm up 
​Category: General Skills  
​Difficulty: Easy  
​Technique: Number base conversion (Hexadecimal to Decimal)  
​What you learned: How positional base-16 (hexadecimal) values work, how to convert hex representations (such as 0x3D) into base-10 decimal format (61), and how to format the result into a valid flag.
Lab Title: Warmed Up Number Base Conversion
​In this lab, I worked on understanding how different number systems relate to each other by completing the Warmed Up challenge on the CyLab Security Academy platform.  
​The problem gave me a hexadecimal number, 0x3D, and asked for its decimal equivalent. Hexadecimal uses base 16, meaning each column represents a power of 16. Working through the math, the first character 3 multiplied by 16 gave 48, and the character D translated to the decimal number 13 in the ones column. Adding these values together resulted in 61.  
​This challenge helped me practice manual conversion between base 16 and base 10 systems without needing automated calculators, reinforcing my understanding of how computers and low-level programs handle data representation.
